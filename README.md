
# 4-Bit ALU – Verilog Implementation

This repository contains the design and verification of a 4-bit Arithmetic Logic Unit (ALU) implemented in Verilog HDL.

## Overview
The ALU performs basic arithmetic and logical operations on two 4-bit inputs based on a control signal. The design focuses on understanding combinational logic, ALU architecture, and functional verification using a testbench.

## Supported Operations
- Addition
- Subtraction
- AND
- OR
- XOR
- NOT (if applicable – remove if not)

## Files
- alu_4bit.v : Verilog module for the 4-bit ALU
- alu_tb.v   : Testbench to verify ALU functionality

## Verification
The testbench applies multiple input combinations and control signals to validate correct operation of the ALU. Simulation can be run using tools such as ModelSim or Icarus Verilog.

## Learning Outcome
- Practical understanding of ALU architecture
- Hands-on experience with Verilog HDL
- Writing and analyzing testbenches for digital designs
- Strengthening digital logic and VLSI fundamentals

## Tools Used
- Verilog HDL
- Digital logic concepts
- Simulation tools (ModelSim / Icarus Verilog)
